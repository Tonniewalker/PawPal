# PawPal เลี้ยงน้องหมา (IG342 PWA)

เว็บแอป PWA สำหรับเลี้ยงน้องหมา ผู้ใช้ต้องแวะมาให้อาหาร ให้น้ำ และลูบหัวน้องทุกวัน
ข้อมูลทั้งหมดเก็บใน **localStorage** และใช้ **เวลาที่บันทึกไว้ (timestamp)** คำนวณว่าผู้ใช้หายไปนานแค่ไหน
ถ้าหายไปนาน น้องหมาจะหิว หิวน้ำ หรือเศร้า

---

## วิธีรัน

```bash
cd pawpal
npm install
npm run dev
```

ดูแบบ PWA จริง (มี Service Worker ใช้ออฟไลน์ได้):

```bash
npm run build
npm run preview
```

## คำนวณเวลาที่หายไปจาก timestamp

**ตัวอย่าง**
- 08:00 เปิดแอป น้ำ = 70 → แอปบันทึก `lastUpdated = 08:00`
- ปิดแอปไป แล้วเปิดใหม่ตอน 13:00
- เวลาที่ผ่านไป = 13:00 − 08:00 = 5 ชั่วโมง
- น้ำลดชั่วโมงละ 10 → 70 − (5 × 10) = **20** → ต่ำกว่า 30 = **หิวน้ำ**
- บันทึก `lastUpdated = 13:00` ใหม่ทันที (ถ้าไม่บันทึก ครั้งหน้าจะลบซ้ำตั้งแต่ 08:00)

**ดูโค้ดได้ที่**
- `dogLogic.js` → ฟังก์ชัน `applyTime(dog, now)` คือสูตรด้านบน
- `App.jsx` → ฟังก์ชัน `startUp()` ทำงานตอนเปิดแอป: Load → คำนวณเวลาที่หายไป → ลดค่า
- `App.jsx` → `useEffect` + `setInterval` ลดค่าทุก 1 นาทีระหว่างเปิดแอป

## ข้อมูลใน localStorage

| key | เก็บอะไร |
|---|---|
| `dog` | ชื่อ, ค่าอิ่ม/น้ำ/ความสุข (0–100), EXP, วันที่รับเลี้ยง, `lastUpdated` |
| `diary` | รายการบันทึกการดูแล (ล่าสุดอยู่บนสุด เก็บสูงสุด 300 รายการ) |

ตัวอย่าง key `dog`:

```json
{
  "name": "ข้าวตัง",
  "food": 52, "water": 20, "fun": 44,
  "exp": 140,
  "adoptedAt": 1760000000000,
  "lastUpdated": 1760018000000
}
```
